## 1. Purpose

Operational checklist that turns policy requirements into recurring actions.

## 2. Weekly Tasks

- Review critical and high vulnerability alerts from dependency and infrastructure scanners.
- Review failed login, unusual access, and privileged action logs.
- Verify backup jobs completed successfully.

## 3. Monthly Tasks

- Validate MFA enforcement for admin systems.
- Review open security findings and remediation deadlines.
- Review production access list for least privilege.
- Rotate or confirm rotation schedule for high-sensitivity secrets.

## 4. Quarterly Tasks

- Formal privileged access review with evidence of approvals/removals.
- Incident response tabletop or scenario walkthrough.
- Policy and runbook review for architecture/process changes.

## 5. Annual Tasks

- Full policy review and version update.
- Security awareness refresher for staff with production access.
- Disaster recovery and restoration validation test.

## 6. Evidence

Keep evidence for each control activity:

- Date and reviewer
- Actions taken
- Findings and owners
- Completion status
